05
8 Non-Negotiable Guardrails
All are release blockers. Zero exceptions. Zero waivers.
G1
Never Skip PD Approval
State machine blocks CSR_REQUESTED → APPROVED without a recorded PD decision. Architecturally impossible to bypass.
G2
Reject CN/SAN Mismatch
Deterministic verify_cer in native tool. LLM verdict is irrelevant — the code decides.
G3
Halt After 2 Consecutive Errors
PolicyMiddleware loop counter triggers magentic escalation to PD/on-call. No infinite retries.
G4
One Audit Line Per Tool Call
AuditMiddleware runs before every tool invocation. Hash-chained records are tamper-evident.
G5
MCP Output Is Data, Never Instructions
Trust-boundary rule + Prompt Shield + HTML/quoted-reply stripping. Prompt injection defeated architecturally.
G6
Block Wildcard CSRs → CAB
PolicyMiddleware + generate_csr dual enforcement. Wildcard certs require separate CAB approval — hard blocked in v1.
G7
Keys Never Leave HSM
exportable=False, key_type=KeyType.rsa_hsm. Keys generated in and permanently reside in FIPS 140-2 L3 HSM.
G8
No Secrets in Code
Config reads env/KV only. CI pip-audit + Dependabot secret-scan gate on every PR.

08
Security Posture
STRIDE · OWASP LLM Top 10 · OWASP Web Top 10 · Fail-closed design
🎭
Spoofing
Entra MI + MFA claim validation on approval callbacks. Mismatched thread_id → 401.
🔧
Tampering
Hash-chained audit log. WORM Blob with legal hold. Cosmos PITR backup.
📜
Repudiation
100% structured audit per tool call. 7-year immutable records. Purview lineage.
🔍
Info Disclosure
Keys in HSM (non-exportable). Cosmos stores only SHA-256 + Blob URL. No secrets in logs.
🚫
Denial of Service
APIM throttling. Per-downstream rate limiters (PKI 10/min, Jira 60/min, SNOW 30/min).
⬆️
Privilege Escalation
Least-privilege MI. Dev-plane (IBM Bob) denied all run-plane operations at APIM layer.
🎯
Primary Threat: LLM01 Prompt Injection
Mitigated architecturally. Jira comments and PKI email bodies are data — they cannot influence tool selection. Deterministic verifier + HITL gate + whitelisted typed tools form a multi-layer defence. Fail-closed start-up MCP schema drift check halts orchestrator on mismatch.
